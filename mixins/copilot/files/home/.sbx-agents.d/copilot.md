## GitHub Copilot provider

The model provider is GitHub Copilot (the project's `opencode.jsonc` sets the default model; alternatives via `/models`). If Copilot is not signed in, tell the user to run `/connect` in the TUI, pick GitHub Copilot, and enter the code at https://github.com/login/device in their host browser — never ask for or handle Copilot tokens yourself.
